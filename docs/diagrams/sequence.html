InvestorHub — Sequence Diagram

Registration & approval, match request, and real-time chat

1. Registration and Admin Approval

2. Match Request Flow

3. Real-time Chat (Socket.IO)

Diagram 1 — Registration

  • New user registers with role investor or businessman.
  • Status is saved as pending; user is redirected to pending page.
  • Admin approves account; user can then access dashboard.

Diagrams 2 & 3 — Match & Chat

  • Investor views a business post and sends a match request.
  • Businessman accepts; both can start a Socket.IO conversation.
  • Messages are persisted in MongoDB and pushed in real time.
