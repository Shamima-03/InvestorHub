Member flow

  • Login with register loop for new users.
  • If account is pending, user sees approval page only.
  • After activation, fork into parallel activities: browse, post, match, profile, matches.
  • Chat opens only when match is accepted; otherwise path joins directly.

Admin flow

  • Admin login with validation loop on left margin (no overlap).
  • Parallel admin tasks with even column spacing.
  • All paths join before logout.
