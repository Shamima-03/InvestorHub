InvestorHub — Entity Relationship Diagram

Chen notation · mapped from the MongoDB / Mongoose schema

Rectangle = entity   Diamond = relationship   Triangle = inheritance (ISA) PK = primary key   FK = foreign key   UK = unique 1   0..1   1..*   0..*

Legend

  • Chen diamonds name the relationship (HAS PROFILE, AUTHORS, REQUESTS).
  • The ISA triangle is role inheritance: Investor, Businessman, and Admin are USER subtypes (stored as role).
  • Dashed box = associative / junction entity (MongoDB participants[]).
  • REPORT.targetId is polymorphic: it points to USER or POST.

Cardinality notes

  • A user has at most one investor profile and/or one businessman profile (1 : 0..1).
  • A user authors many posts. A match optionally refers to one post (0..1).
  • A match pair (investorId, businessmanId) is unique.
  • Conversation–User is M:N; two participants per conversation in this system.
  • Every message has exactly one sender (USER); a user sends many messages.
