Cardinality notes (for the report)

  • A user has at most one investor profile and/or one businessman profile (role-based 1:0..1).
  • A user authors many posts. A match optionally refers to one post.
  • A match pair (investor, businessman) is unique.
  • Conversation–User is M:N; MongoDB stores it as participants[]. The junction table is the relational view.
  • Report.targetId is polymorphic: it points to either User or Post.
