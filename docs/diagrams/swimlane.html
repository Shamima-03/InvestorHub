InvestorHub — Swimlane Diagram

Member · System · Admin — single unified workflow

Flow summary

  • Member registers → system saves as pending → admin approves.
  • Member browses posts, creates post, and sends match request.
  • Other member accepts → chat opens → payment via SSLCommerz.
  • Control flow (solid) stays inside a row or steps to the next lane; the admin’s approval comes back to the member as a dashed notification routed through the free gap below the row, so it crosses no box and no other line.
  • No flow passes through an activity box, every arrowhead lands on a box edge, and no two flows cross.
