How to put these in the report

  1. Open a diagram in the browser.
  2. Click Print / Save as PDF.
  3. Choose destination Save as PDF, paper size A3 landscape (or A4 landscape).
  4. Insert that PDF/screenshot into the thesis or slide.

Mermaid sources are in erd.mmd and usecase.mmd if you want to edit them on mermaid.live.
