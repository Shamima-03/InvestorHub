InvestorHub diagrams

University submission diagrams based on the actual InvestorHub codebase (MongoDB models, Express API, React frontend, Socket.IO chat).

Structural

1. Entity Relationship Diagram (ERD)

User, profiles, Post, Match, Conversation, Message, Report — Crow's Foot notation.

2. Use Case Diagram

Guest, Registered User, Investor, Businessman, Administrator — include / extend.

Behavioral & Data Flow

3. Swimlane Diagram

Guest/Member, Administrator, and System lanes with cross-lane interactions.

4. Activity Diagram

Member and Admin behavioral flows with fork/join parallel activities.

5. Sequence Diagram

Registration & approval, match request, and real-time chat (Socket.IO).

6. Data Flow Diagram (DFD)

Level 0 (context), Level 1 (decomposition), Level 2 (Match Management detail).

Export for report

  1. Open any diagram in the browser.
  2. Click Print / Save as PDF.
  3. Paper size: A3 landscape (or A4 landscape).
  4. Insert the PDF into your thesis or presentation.

Mermaid source files (*.mmd) are included for editing on mermaid.live.
